# MLStudio Pro Foundation Seal (V1-V3.1)

The foundation of MLStudio Pro is sealed. No modifications are permitted to the core curriculum or baseline runtime engine to ensure absolute pedagogical and execution integrity.

## Sealed Components
- `core/content/curriculum/foundations/`
- `core/content/labs/foundations/`
- `core/runtime/engine/`

## Modification Policy
- Any new features must be additives in `advanced/` or `extensions/`.
- No removal of V1 topics.
- No changes to default seeds or output contracts.
