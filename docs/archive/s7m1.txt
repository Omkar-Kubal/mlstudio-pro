Digital Images: The Foundation
Before we can process images with AI, we must understand how computers "see" them. Unlike humans who perceive continuous visual scenes, computers represent images as discrete numerical arrays.
RGB Color Model
Most digital images use the RGB (Red, Green, Blue) color model:
Color = R + G + B

Example:
White  = (255, 255, 255)  # All colors at max
Black  = (0, 0, 0)        # All colors at min
Red    = (255, 0, 0)      # Only red channel
Purple = (128, 0, 128)    # Red + Blue
Image as a 3D Tensor
A color image is represented as a 3-dimensional array:
Image Shape: (Height, Width, Channels)

Example: 1920×1080 Full HD image
Shape: (1080, 1920, 3)
Total pixels: 1080 × 1920 = 2,073,600 pixels
Total values: 2,073,600 × 3 = 6,220,800 numbers
Pixel Values and Data Types

uint8 (most common): Values 0-255

Memory efficient: 1 byte per channel
Standard for display and storage


float32/float64: Values typically 0.0-1.0 or -1.0 to 1.0

Used during neural network training
Allows gradients and precise calculations



Grayscale Images
Single-channel images representing intensity:
Grayscale conversion (weighted average):
Gray = 0.299 × R + 0.587 × G + 0.114 × B

Why weighted? Human eyes are most sensitive to green!
Image Coordinates
Origin (0,0) typically at top-left:

(0,0) ──────► X (width)
  │
  │
  ▼
  Y (height)

Pixel at (y, x) accessed as: image[y, x, :]
Color Spaces Beyond RGB

HSV (Hue, Saturation, Value)

Hue: Color type (0-360°)
Saturation: Color intensity (0-100%)
Value: Brightness (0-100%)
Better for color-based segmentation


LAB (Lightness, A, B)

L: Lightness (0-100)
A: Green-Red axis
B: Blue-Yellow axis
Perceptually uniform (distance = perceived difference)


YCbCr (used in JPEG compression)

Y: Luminance (brightness)
Cb, Cr: Chrominance (color information)

Topic 2: Image Classification
Conceptual Explanation
What is Image Classification?
Image classification is the task of assigning a label (or class) to an entire image from a predefined set of categories. It's one of the most fundamental computer vision tasks.
Input: Image (e.g., photo of an animal)
Output: Class label (e.g., "cat", "dog", "bird")
Problem Formulation
Given:

Training dataset: {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}

xᵢ = image (e.g., 224×224×3 tensor)
yᵢ = class label (e.g., 0, 1, 2, ..., C-1 for C classes)



Goal: Learn function f(x) → y that predicts correct class for new images
The Classification Pipeline

Input: Raw image (various sizes, formats)
Preprocessing: Resize, normalize, augment
Feature Extraction: CNN layers extract hierarchical features
Classification: Fully connected layers map features to class probabilities
Output: Probability distribution over classes (softmax)

Mathematical Framework
For a C-class problem:
1. Forward pass through CNN:
   z = CNN(x; θ)  # Extract features
   
2. Classification layer:
   logits = W·z + b  # Linear transformation
   
3. Softmax for probabilities:
   P(y=c|x) = exp(logits[c]) / Σexp(logits[i])
   
4. Prediction:
   ŷ = argmax(P(y|x))
Loss Functions
1. Categorical Cross-Entropy (most common)
For one-hot encoded labels:
L = -Σ yc · log(ŷc)

Where:
- yc = 1 if true class is c, else 0
- ŷc = predicted probability for class c

Example:
True: [0, 1, 0]  (class 1)
Pred: [0.1, 0.7, 0.2]
Loss = -(0·log(0.1) + 1·log(0.7) + 0·log(0.2))
     = -log(0.7) = 0.357
2. Sparse Categorical Cross-Entropy
For integer labels (more memory efficient):
L = -log(ŷy)

Where y is the true class index
Evaluation Metrics

Accuracy: Fraction of correct predictions

   Accuracy = (TP + TN) / Total

Simple, intuitive
Misleading for imbalanced datasets


Precision: Of predicted positives, how many are correct?

   Precision = TP / (TP + FP)

Important when false positives are costly


Recall (Sensitivity): Of actual positives, how many did we find?

   Recall = TP / (TP + FN)

Important when false negatives are costly


F1 Score: Harmonic mean of precision and recall

   F1 = 2 · (Precision · Recall) / (Precision + Recall)

Balanced metric for imbalanced datasets


Confusion Matrix: Shows all prediction combinations

             Predicted
           Cat  Dog  Bird
   Actual
   Cat     45    3    2
   Dog      2   48    0
   Bird     1    0   49

Top-K Accuracy: Correct label in top K predictions

   Top-5 Accuracy: True label in top 5 predictions?
   Useful for large number of classes (ImageNet: 1000 classes)
Common Architectures for Classification
Simple CNN:
Input → Conv → Pool → Conv → Pool → Flatten → Dense → Softmax

VGG-style:
Input → [Conv→Conv→Pool]×3 → Flatten → Dense → Softmax

ResNet-style:
Input → [ResBlock]×N → GlobalAvgPool → Dense → Softmax

Modern Efficient:
Input → EfficientNet/MobileNet → GlobalAvgPool → Dense → Softmax
Data Augmentation (Critical for good performance)
pythonAugmentations during training:
- Random horizontal flip
- Random rotation (±15°)
- Random zoom (0.8-1.2×)
- Random brightness/contrast adjustment
- Random crop and resize
- Cutout/mixup (advanced)

Effect: Artificially expands training data, reduces overfitting
```

**Transfer Learning for Classification**

Instead of training from scratch:

1. **Load pretrained model** (trained on ImageNet)
2. **Remove final classification layer**
3. **Add new classification layer** for your classes
4. **Fine-tune** on your dataset
```

Benefits:

Faster training
Better accuracy with less data
Leverages learned features

Common Challenges

Class Imbalance: Some classes have many more examples

Solutions: Weighted loss, oversampling, SMOTE


Overfitting: Model memorizes training data

Solutions: Data augmentation, dropout, regularization


Similar Classes: Hard to distinguish (e.g., different dog breeds)

Solutions: More data, harder negatives, hierarchical classification


Limited Data: Not enough training examples

Solutions: Transfer learning, data augmentation, few-shot learning


Domain Shift: Training and test data differ

Solutions: Domain adaptation, diverse training data

pythonimport numpy as np
import matplotlib.pyplot as plt

# Build a simple CNN classifier
def build_classifier(input_shape=(224, 224, 3), num_classes=10):
    """
    Build a CNN for image classification
    """
    model = models.Sequential([
        # Block 1
        layers.Conv2D(32, (3, 3), activation='relu', padding='same', 
                     input_shape=input_shape),
        layers.BatchNormalization(),
        layers.Conv2D(32, (3, 3), activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),
        
        # Block 2
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),
        
        # Block 3
        layers.Conv2D(128, (3, 3), activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.Conv2D(128, (3, 3), activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),
        
        # Classifier
        layers.GlobalAveragePooling2D(),
        layers.Dense(256, activation='relu'),
        layers.BatchNormalization(),
        layers.Dropout(0.5),
        layers.Dense(num_classes, activation='softmax')
    ], name='ImageClassifier')
    
    return model

# Train on CIFAR-10 (example dataset)
def train_cifar10_classifier():
    """
    Complete example: Train classifier on CIFAR-10
    """
    # Load data
    (x_train, y_train), (x_test, y_test) = keras.datasets.cifar10.load_data()
    
    # Normalize
    x_train = x_train.astype('float32') / 255.0
    x_test = x_test.astype('float32') / 255.0
    
    # Class names
    class_names = ['airplane', 'automobile', 'bird', 'cat', 'deer', 
                   'dog', 'frog', 'horse', 'ship', 'truck']
    
    print("Dataset Information:")
    print(f"Training samples: {len(x_train)}")
    print(f"Test samples: {len(x_test)}")
    print(f"Image shape: {x_train.shape[1:]}")
    print(f"Number of classes: {len(class_names)}\n")
    
    # Build model
    model = build_classifier(input_shape=(32, 32, 3), num_classes=10)
    
    # Compile
    model.compile(
        optimizer=keras.optimizers.Adam(learning_rate=0.001),
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    
    print("Model Architecture:")
    model.summary()
    
    # Data augmentation
    datagen = ImageDataGenerator(
        rotation_range=15,
        width_shift_range=0.1,
        height_shift_range=0.1,
        horizontal_flip=True,
        zoom_range=0.1
    )
    
    # Callbacks
    callbacks = [
        keras.callbacks.EarlyStopping(patience=10, restore_best_weights=True),
        keras.callbacks.ReduceLROnPlateau(factor=0.5, patience=5, verbose=1)
    ]
    
    # Train
    print("\nTraining model...")
    history = model.fit(
        datagen.flow(x_train, y_train, batch_size=64),
        validation_data=(x_test, y_test),
        epochs=30,
        callbacks=callbacks,
        verbose=1
    )
    
    return model, history, x_test, y_test, class_names

# Create confusion matrix
def plot_confusion_matrix(model, x_test, y_test, class_names):
    """
    Generate and visualize confusion matrix
    """
    # Predictions
    y_pred = model.predict(x_test, verbose=0)
    y_pred_classes = np.argmax(y_pred, axis=1)
    y_true = y_test.flatten()
    
    # Compute confusion matrix
    cm = confusion_matrix(y_true, y_pred_classes)
    
    # Normalize
    cm_normalized = cm.astype('float') / cm.sum(axis=1)[:, np.newaxis]
    
    # Plot
    fig, axes = plt.subplots(1, 2, figsize=(16, 6))
    
    # Raw counts
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
                xticklabels=class_names, yticklabels=class_names,
                ax=axes[0], cbar_kws={'label': 'Count'})
    axes[0].set_title('Confusion Matrix (Counts)', fontsize=13, fontweight='bold')
    axes[0].set_ylabel('True Label')
    axes[0].set_xlabel('Predicted Label')
    
    # Normalized
    sns.heatmap(cm_normalized, annot=True, fmt='.2f', cmap='RdYlGn', 
                xticklabels=class_names, yticklabels=class_names,
                ax=axes[1], cbar_kws={'label': 'Proportion'}, vmin=0, vmax=1)
    axes[1].set_title('Confusion Matrix (Normalized)', fontsize=13, fontweight='bold')
    axes[1].set_ylabel('True Label')
    axes[1].set_xlabel('Predicted Label')
    
    plt.tight_layout()
    plt.savefig('confusion_matrix.png', dpi=150, bbox_inches='tight')
    plt.close()
    
    # Print classification report
    print("\nClassification Report:")
    print("="*80)
    print(classification_report(y_true, y_pred_classes, target_names=class_names))
    print("="*80)

def analyze_per_class_accuracy(model, x_test, y_test, class_names):

```
### Topic 3: Object Detection

#### Conceptual Explanation

**Object Detection vs Image Classification**
```
Image Classification:
Input: Image
Output: Single label (e.g., "dog")

Object Detection:
Input: Image
Output: Multiple objects with:
  - Class labels (e.g., "dog", "cat", "person")
  - Bounding boxes (x, y, width, height)
  - Confidence scores
```

**Problem Definition**

Given an image, detect all objects by:
1. **Localization**: Where is the object? (bounding box)
2. **Classification**: What is the object? (class label)

**Bounding Box Representation**

Multiple formats:
```
1. (x_min, y_min, x_max, y_max)  # Top-left and bottom-right corners
2. (x_center, y_center, width, height)  # Center and dimensions
3. (x_min, y_min, width, height)  # Top-left corner and dimensions
```

**Key Metrics**

**1. Intersection over Union (IoU)**

Measures overlap between predicted and ground truth boxes:
```
IoU = Area of Overlap / Area of Union

Example:
Ground Truth: [10, 10, 50, 50]
Prediction:   [15, 15, 55, 55]

Overlap area = 35 × 35 = 1,225
Union area = (40×40) + (40×40) - 1,225 = 1,975
IoU = 1,225 / 1,975 = 0.62
IoU thresholds:

IoU ≥ 0.5: "Good" detection
IoU ≥ 0.7: "Very good" detection
IoU ≥ 0.9: "Excellent" detection

2. Precision and Recall
Precision = TP / (TP + FP)  # Of detected objects, how many are correct?
Recall = TP / (TP + FN)     # Of ground truth objects, how many were detected?
Where:

TP (True Positive): Correct detection (IoU ≥ threshold)
FP (False Positive): Incorrect detection or duplicate
FN (False Negative): Missed object


**3. Average Precision (AP)**

Area under Precision-Recall curve:
AP = ∫₀¹ Precision(Recall) dRecall

**4. Mean Average Precision (mAP)**

Average of AP across all classes:
mAP = (1/C) × Σ AP_c
Common variants:

mAP@0.5: IoU threshold = 0.5
mAP@[0.5:0.95]: Average over IoU thresholds from 0.5 to 0.95


**Object Detection Approaches**

### 1. **Two-Stage Detectors** (R-CNN Family)

**R-CNN (2014)**

Generate ~2000 region proposals (Selective Search)
Warp each region to fixed size
Extract CNN features for each region
Classify with SVM
Refine bounding box with regression


Slow: ~47 seconds per image

**Fast R-CNN (2015)**

Run CNN once on entire image
Generate region proposals
Use RoI Pooling to extract features from feature map
Classify and regress bounding boxes


Faster: ~2 seconds per image

**Faster R-CNN (2015)**

Run CNN backbone on image → feature map
Region Proposal Network (RPN) generates proposals
RoI Pooling extracts features
Classification + Bounding box regression


Even faster: ~0.2 seconds per image
More accurate but still not real-time

---

### 2. **Single-Stage Detectors** (Faster but slightly less accurate)

**YOLO (You Only Look Once)**

Key idea: Treat detection as regression problem

Divide image into S×S grid (e.g., 7×7)
Each grid cell predicts:

B bounding boxes (e.g., 2)
Confidence for each box
C class probabilities


Output: S×S×(B×5 + C) tensor

For YOLO v1 on PASCAL VOC (20 classes):
7×7×(2×5 + 20) = 7×7×30 = 1,470 predictions

**Non-Maximum Suppression (NMS)**

Problem: Multiple detections for same object

Solution:

Sort all detections by confidence
Select highest confidence detection
Remove all detections with IoU > threshold (e.g., 0.5)
Repeat until no detections remain


**SSD (Single Shot MultiBox Detector)**

Uses multiple feature maps at different scales
Predicts boxes at multiple scales
Better for detecting small objects


**YOLOv3, YOLOv4, YOLOv5, YOLOv8** (Evolution)

Improvements:
- Multi-scale predictions
- Better backbone networks
- Improved loss functions
- Data augmentation techniques
- Real-time performance (30-60 FPS)

---

### 3. **Modern Approaches**

**EfficientDet**
- Compound scaling for backbone and detection head
- BiFPN (Bidirectional Feature Pyramid Network)
- Better accuracy-efficiency trade-off

**DETR (Detection Transformer)**
- Uses Transformer architecture
- No hand-crafted components (anchors, NMS)
- Set prediction approach

**Loss Functions for Object Detection**

Combined loss with multiple components:
```python
Total Loss = λ₁ × Classification Loss
           + λ₂ × Localization Loss  
           + λ₃ × Confidence Loss

1. Classification Loss (Cross-Entropy):
   L_cls = -Σ y_c · log(ŷ_c)

2. Localization Loss (Smooth L1 or IoU-based):
   L_loc = Smooth_L1(bbox_pred, bbox_gt)
   
   Or IoU Loss:
   L_IoU = 1 - IoU(bbox_pred, bbox_gt)

3. Confidence Loss (Binary Cross-Entropy):
   L_conf = -[obj · log(conf) + (1-obj) · log(1-conf)]
   
   Where obj = 1 if object present, 0 otherwise
```

**Anchor Boxes**

Predefined boxes of different scales and aspect ratios:
Scales: [32, 64, 128, 256, 512] pixels
Aspect Ratios: [1:1, 1:2, 2:1]
Total anchors per location: 5 scales × 3 ratios = 15 anchors

Model predicts offsets from anchors:
Δx, Δy: Center offset
Δw, Δh: Width/height scaling
Predicted box:
x = x_anchor + Δx
y = y_anchor + Δy
w = w_anchor × exp(Δw)
h = h_anchor × exp(Δh)

**Challenges in Object Detection**

1. **Scale Variation**: Objects appear at different sizes
   - Solution: Feature Pyramid Networks, multi-scale predictions

2. **Occlusion**: Objects partially hidden
   - Solution: Context modeling, better features

3. **Class Imbalance**: Background >> objects
   - Solution: Focal Loss, hard negative mining

4. **Real-time Processing**: Need fast inference
   - Solution: YOLO, MobileNet-SSD

5. **Small Object Detection**: Tiny objects hard to detect
   - Solution: High-resolution feature maps, attention mechanisms

# IoU calculation
def calculate_iou(box1, box2):
    """
    Calculate Intersection over Union
    
    Boxes in format: [x_min, y_min, x_max, y_max]
    """
    # Calculate intersection coordinates
    x_min_inter = max(box1[0], box2[0])
    y_min_inter = max(box1[1], box2[1])
    x_max_inter = min(box1[2], box2[2])
    y_max_inter = min(box1[3], box2[3])
    
    # Calculate intersection area
    if x_max_inter < x_min_inter or y_max_inter < y_min_inter:
        intersection = 0.0
    else:
        intersection = (x_max_inter - x_min_inter) * (y_max_inter - y_min_inter)
    
    # Calculate union area
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - intersection
    
    # Calculate IoU
    iou = intersection / union if union > 0 else 0.0
    
    return iou

# Non-Maximum Suppression
def non_max_suppression(boxes, scores, iou_threshold=0.5):
    """
    Apply Non-Maximum Suppression
    
    Args:
        boxes: List of boxes [x_min, y_min, x_max, y_max]
        scores: Confidence scores for each box
        iou_threshold: IoU threshold for suppression
    
    Returns:
        keep_indices: Indices of boxes to keep
    """
    # Sort by confidence score (descending)
    indices = np.argsort(scores)[::-1]
    
    keep = []
    
    while len(indices) > 0:
        # Keep highest confidence box
        current = indices[0]
        keep.append(current)
        
        # Calculate IoU with remaining boxes
        ious = np.array([calculate_iou(boxes[current], boxes[i]) 
                        for i in indices[1:]])
        
        # Remove boxes with high IoU
        indices = indices[1:][ious < iou_threshold]
    
    return keep

# Simple object detector architecture (conceptual)
def build_simple_detector(input_shape=(416, 416, 3), num_classes=20, num_anchors=3):
    """
    Simplified YOLO-style detector
    
    Note: This is educational - real YOLO is more complex
    """
    inputs = layers.Input(shape=input_shape)
    
    # Backbone (feature extractor)
    x = layers.Conv2D(32, (3, 3), strides=2, padding='same')(inputs)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.1)(x)
    
    x = layers.Conv2D(64, (3, 3), strides=2, padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.1)(x)
    
    x = layers.Conv2D(128, (3, 3), strides=2, padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.1)(x)
    
    x = layers.Conv2D(256, (3, 3), strides=2, padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.1)(x)
    
    # Detection head
    # Output: Grid × Grid × (Anchors × (5 + Classes))
    # 5 = x, y, w, h, confidence
    grid_size = input_shape[0] // 16  # After 4 stride-2 convs: 416→26
    output_channels = num_anchors * (5 + num_classes)
    
    x = layers.Conv2D(output_channels, (1, 1), padding='same')(x)
    x = layers.Reshape((grid_size, grid_size, num_anchors, 5 + num_classes))(x)
    
    model = models.Model(inputs=inputs, outputs=x, name='SimpleDetector')
    
    return model

# Calculate mAP
def calculate_map(predictions, ground_truths, iou_threshold=0.5, num_classes=20):
    """
    Calculate mean Average Precision
    
    Simplified version for educational purposes
    """
    aps = []
    
    for class_id in range(num_classes):
        # Filter predictions and ground truths for this class
        class_preds = [p for p in predictions if p['class'] == class_id]
        class_gts = [g for g in ground_truths if g['class'] == class_id]
        
        if len(class_gts) == 0:
            continue
        
        # Sort predictions by confidence
        class_preds = sorted(class_preds, key=lambda x: x['score'], reverse=True)
        
        # Match predictions to ground truths
        tp = np.zeros(len(class_preds))
        fp = np.zeros(len(class_preds))
        matched_gts = set()
        
        for i, pred in enumerate(class_preds):
            best_iou = 0
            best_gt_idx = -1
            
            for j, gt in enumerate(class_gts):
                if j in matched_gts:
                    continue
                
                iou = calculate_iou(pred['box'], gt['box'])
                if iou > best_iou:
                    best_iou = iou
                    best_gt_idx = j
            
            if best_iou >= iou_threshold:
                tp[i] = 1
                matched_gts.add(best_gt_idx)
            else:
                fp[i] = 1
        
        # Calculate precision and recall
        tp_cumsum = np.cumsum(tp)
        fp_cumsum = np.cumsum(fp)
        
        recalls = tp_cumsum / len(class_gts)
        precisions = tp_cumsum / (tp_cumsum + fp_cumsum)
        
        # Calculate AP (simplified - 11-point interpolation)
        ap = 0
        for t in np.linspace(0, 1, 11):
            precs_above_t = precisions[recalls >= t]
            if len(precs_above_t) > 0:
                ap += np.max(precs_above_t) / 11
        
        aps.append(ap)
    
    # Calculate mAP
    mAP = np.mean(aps) if len(aps) > 0 else 0
    
    return mAP, aps

Topic 4: Transfer Learning (Computer Vision)
Conceptual Explanation
What is Transfer Learning?
Transfer learning is the practice of taking a model trained on one task and adapting it for a different but related task. Instead of training from scratch, you leverage knowledge already learned.
The Core Idea
Traditional Learning:
Task A: Train from scratch → Model A
Task B: Train from scratch → Model B
(Each requires massive data and computation)

Transfer Learning:
Task A (ImageNet): Train → Model A (pretrained)
Task B (Your task): Fine-tune Model A → Model B
(Requires less data and computation)
Why Transfer Learning Works
CNNs learn hierarchical features:

Early layers: Generic features (edges, colors, textures)
Middle layers: Patterns and parts (eyes, wheels, leaves)
Late layers: Task-specific features (specific to ImageNet classes)

Key insight: Early and middle layer features are transferable across different vision tasks!
The ImageNet Pretraining Paradigm
Most pretrained models are trained on ImageNet:

1.2 million training images
1,000 object categories
Models achieve ~70-90% top-1 accuracy

Popular pretrained models:

VGG16/VGG19
ResNet50/ResNet101/ResNet152
InceptionV3/InceptionResNetV2
MobileNetV2/MobileNetV3
EfficientNet B0-B7
Vision Transformers (ViT)

Transfer Learning Strategies
1. Feature Extraction (Frozen Backbone)
Pretrained CNN (frozen) → Remove top → Add new classifier → Train classifier only

Steps:
1. Load pretrained model without top layer
2. Freeze all convolutional layers (trainable=False)
3. Add new classification layers for your task
4. Train only new layers
When to use: Small dataset, task similar to ImageNet
Advantages:

Fast training
Requires less data
Prevents overfitting

Disadvantages:

Limited adaptation to new task

2. Fine-Tuning (Partial Unfreezing)
Pretrained CNN → Unfreeze last N layers → Train with low learning rate

Steps:
1. Start with feature extraction approach
2. After initial training, unfreeze last few layers
3. Continue training with very low learning rate (e.g., 0.0001)
4. Fine-tune these layers to your specific task
When to use: Medium dataset, somewhat different from ImageNet
Advantages:

Better task adaptation
Still leverages pretrained features

Disadvantages:

Risk of overfitting if not careful
Requires more computation

3. Full Fine-Tuning (All Layers)
Pretrained CNN → Unfreeze all layers → Train entire network

Steps:
1. Load pretrained weights
2. Unfreeze all layers
3. Train entire network with low learning rate
When to use: Large dataset, task different from ImageNet
Advantages:

Maximum adaptation to new task
Best potential performance

Disadvantages:

Requires significant data
Computationally expensive
Risk of catastrophic forgetting

Decision Tree for Transfer Learning
How much data do you have?

├─ Very small (<1,000 images)
│  └─ Feature extraction only
│     • Freeze all conv layers
│     • Train small classifier
│
├─ Small (1,000 - 10,000 images)
│  └─ Feature extraction + light fine-tuning
│     • Start with frozen conv layers
│     • Unfreeze last 1-2 blocks
│
├─ Medium (10,000 - 100,000 images)
│  └─ Progressive fine-tuning
│     • Start with frozen base
│     • Gradually unfreeze more layers
│
└─ Large (>100,000 images)
   └─ Full fine-tuning or train from scratch
      • Consider training from scratch
      • Or fine-tune all layers
Learning Rate Strategies

Pretrained models expect specific preprocessing:

Common Pitfalls

Forgetting to freeze layers: Accidentally training all layers with small data
Wrong preprocessing: Not using model-specific preprocessing
Learning rate too high: Destroying pretrained weights
Wrong input size: Not resizing to expected dimensions
Batch normalization issues: Keeping BN layers frozen during fine-tuning

Domain Adaptation Challenges
Transfer learning works best when:

Source and target domains are similar (ImageNet → CIFAR-10: ✓)
Source and target tasks are related (classification → classification: ✓)

Challenges when domains differ:

ImageNet (natural images) → Medical X-rays (different domain)
ImageNet (RGB) → Satellite imagery (different modality)
ImageNet (single object) → Dense scenes (different context)

Solutions:

Domain adaptation techniques
Multi-stage transfer learning
Self-supervised pretraining on target domain

# Load pretrained model for feature extraction
def create_feature_extractor(base_model_name='ResNet50', num_classes=10, 
                             input_shape=(224, 224, 3)):
    """
    Create feature extraction model (frozen base)
    """
    # Load pretrained base model
    base_models = {
        'ResNet50': ResNet50,
        'VGG16': VGG16,
        'MobileNetV2': MobileNetV2,
        'EfficientNetB0': EfficientNetB0
    }
    
    base_model = base_models[base_model_name](
        weights='imagenet',
        include_top=False,
        input_shape=input_shape
    )
    
    # Freeze base model
    base_model.trainable = False
    
    # Add custom top
    inputs = keras.Input(shape=input_shape)
    x = base_model(inputs, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dense(256, activation='relu')(x)
    x = layers.Dropout(0.5)(x)
    outputs = layers.Dense(num_classes, activation='softmax')(x)
    
    model = models.Model(inputs, outputs, name=f'{base_model_name}_FeatureExtractor')
    
    # Count trainable parameters
    trainable_params = sum([keras.backend.count_params(w) for w in model.trainable_weights])
    non_trainable_params = sum([keras.backend.count_params(w) for w in model.non_trainable_weights])
    
    print(f"\n{base_model_name} Feature Extractor:")
    print(f"Trainable parameters: {trainable_params:,}")
    print(f"Non-trainable parameters: {non_trainable_params:,}")
    print(f"Total parameters: {trainable_params + non_trainable_params:,}\n")
    
    return model

# Fine-tuning model
def create_fine_tuning_model(base_model_name='ResNet50', num_classes=10,
                            unfreeze_layers=50, input_shape=(224, 224, 3)):
    """
    Create fine-tuning model (partially unfrozen base)
    """
    base_models = {
        'ResNet50': ResNet50,
        'VGG16': VGG16,
        'MobileNetV2': MobileNetV2,
        'EfficientNetB0': EfficientNetB0
    }
    
    base_model = base_models[base_model_name](
        weights='imagenet',
        include_top=False,
        input_shape=input_shape
    )
    
    # Freeze early layers, unfreeze later layers
    base_model.trainable = True
    
    for layer in base_model.layers[:-unfreeze_layers]:
        layer.trainable = False
    
    # Add custom top
    inputs = keras.Input(shape=input_shape)
    x = base_model(inputs, training=True)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dense(256, activation='relu')(x)
    x = layers.Dropout(0.5)(x)
    outputs = layers.Dense(num_classes, activation='softmax')(x)
    
    model = models.Model(inputs, outputs, name=f'{base_model_name}_FineTuned')
    
    # Count trainable parameters
    trainable_params = sum([keras.backend.count_params(w) for w in model.trainable_weights])
    non_trainable_params = sum([keras.backend.count_params(w) for w in model.non_trainable_weights])
    
    print(f"\n{base_model_name} Fine-Tuning Model:")
    print(f"Unfrozen layers: {unfreeze_layers}")
    print(f"Trainable parameters: {trainable_params:,}")
    print(f"Non-trainable parameters: {non_trainable_params:,}")
    print(f"Total parameters: {trainable_params + non_trainable_params:,}\n")
    
    return model

    strategies = {
        'Feature Extraction': create_feature_extractor('ResNet50', num_classes),
        'Fine-Tuning (50 layers)': create_fine_tuning_model('ResNet50', num_classes, 50),
    }
    
    histories = {}
    
    for name, model in strategies.items():
        print(f"\nTraining {name}...")
        
        # Compile
        lr = 1e-4 if 'Fine-Tuning' in name else 1e-3
        model.compile(
            optimizer=keras.optimizers.Adam(learning_rate=lr),
            loss='sparse_categorical_crossentropy',
            metrics=['accuracy']
        )
        
        # Train
        history = model.fit(
            x_train, y_train,
            validation_data=(x_val, y_val),
            epochs=epochs,
            batch_size=32,
            verbose=0
        )
        
        histories[name] = history
        
        print(f"Final validation accuracy: {history.history['val_accuracy'][-1]:.4f}")
    
    return histories

# Visualize layer freezing
def visualize_layer_freezing(model):
    """
    Visualize which layers are trainable vs frozen
    """
    layer_names = []
    trainable_status = []
    param_counts = []
    
    for layer in model.layers:
        if hasattr(layer, 'layers'):  # If it's a base model
            for sublayer in layer.layers:
                layer_names.append(sublayer.name)
                trainable_status.append(sublayer.trainable)
                param_counts.append(sublayer.count_params())
        else:
            layer_names.append(layer.name)
            trainable_status.append(layer.trainable)
            param_counts.append(layer.count_params())
    
    # Create visualization
    fig, axes = plt.subplots(1, 2, figsize=(16, max(8, len(layer_names) * 0.3)))
    
    # Plot 1: Layer status
    colors = ['orange' if t else 'steelblue' for t in trainable_status]
    y_pos = np.arange(len(layer_names))
    
    axes[0].barh(y_pos, [1]*len(layer_names), color=colors, edgecolor='black')
    axes[0].set_yticks(y_pos)
    axes[0].set_yticklabels(layer_names, fontsize=6)
    axes[0].set_xlabel('Layer Status')
    axes[0].set_title('Trainable (Orange) vs Frozen (Blue) Layers', 
                     fontsize=12, fontweight='bold')
    axes[0].set_xticks([])
    axes[0].invert_yaxis()
    
    # Add legend
    from matplotlib.patches import Patch
    legend_elements = [
        Patch(facecolor='orange', edgecolor='black', label='Trainable'),
        Patch(facecolor='steelblue', edgecolor='black', label='Frozen')
    ]
    axes[0].legend(handles=legend_elements, loc='lower right')
    
    # Plot 2: Parameter distribution
    axes[1].barh(y_pos, param_counts, color=colors, edgecolor='black')
    axes[1].set_yticks(y_pos)
    axes[1].set_yticklabels(layer_names, fontsize=6)
    axes[1].set_xlabel('Number of Parameters')
    axes[1].set_title('Parameters per Layer', fontsize=12, fontweight='bold')
    axes[1].set_xscale('log')
    axes[1].invert_yaxis()
    axes[1].grid(axis='x', alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('layer_freezing_visualization.png', dpi=150, bbox_inches='tight')
    plt.close()
    
    # Print summary
    trainable_params = sum([p for p, t in zip(param_counts, trainable_status) if t])
    frozen_params = sum([p for p, t in zip(param_counts, trainable_status) if not t])
    
    print("\nLayer Freezing Summary:")
    print("="*60)
    print(f"Trainable layers: {sum(trainable_status)}/{len(trainable_status)}")
    print(f"Trainable parameters: {trainable_params:,}")
    print(f"Frozen parameters: {frozen_params:,}")
    print(f"Total parameters: {trainable_params + frozen_params:,}")
    print("="*60 + "\n")

# Compare training curves
def plot_training_comparison(histories):
    """
    Compare training curves for different strategies
    """
    fig, axes = plt.subplots(1, 2, figsize=(15, 5))
    
    # Accuracy
    for name, history in histories.items():
        axes[0].plot(history.history['accuracy'], label=f'{name} (train)', 
                    linestyle='--', linewidth=2)
        axes[0].plot(history.history['val_accuracy'], label=f'{name} (val)', 
                    linewidth=2)
    
    axes[0].set_xlabel('Epoch', fontsize=12)
    axes[0].set_ylabel('Accuracy', fontsize=12)
    axes[0].set_title('Accuracy Comparison', fontsize=13, fontweight='bold')
    axes[0].legend()
    axes[0].grid(alpha=0.3)
    
    # Loss
    for name, history in histories.items():
        axes[1].plot(history.history['loss'], label=f'{name} (train)', 
                    linestyle='--', linewidth=2)
        axes[1].plot(history.history['val_loss'], label=f'{name} (val)', 
                    linewidth=2)
    
    axes[1].set_xlabel('Epoch', fontsize=12)
    axes[1].set_ylabel('Loss', fontsize=12)
    axes[1].set_title('Loss Comparison', fontsize=13, fontweight='bold')
    axes[1].legend()
    axes[1].grid(alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('transfer_learning_comparison.png', dpi=150, bbox_inches='tight')
    plt.close()

# Visualize feature maps
def visualize_transferred_features(model, image, layer_names=None):
    """
    Visualize features learned by pretrained model on new image
    """
    # Get base model
    base_model = model.layers[1]  # Assuming base model is second layer
    
    if layer_names is None:
        # Select a few layers to visualize
        layer_names = [layer.name for layer in base_model.layers 
                      if 'conv' in layer.name][::10][:6]
    
    # Create feature extractor
    layer_outputs = [base_model.get_layer(name).output for name in layer_names]
    feature_extractor = models.Model(inputs=base_model.input, outputs=layer_outputs)
    
    # Get features
    features = feature_extractor.predict(image[np.newaxis, ...], verbose=0)
    
    # Plot
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))
    axes = axes.flatten()
    
    for i, (feature_map, layer_name) in enumerate(zip(features, layer_names)):
        # Average across channels
        feature_avg = feature_map[0].mean(axis=-1)
        
        ax = axes[i]
        im = ax.imshow(feature_avg, cmap='viridis')
        ax.set_title(f'{layer_name}\nShape: {feature_map.shape[1:]}', 
                    fontsize=10, fontweight='bold')
        ax.axis('off')
        plt.colorbar(im, ax=ax, fraction=0.046)
    
    plt.suptitle('Transferred Features from Pretrained Model', 
                fontsize=14, fontweight='bold')
    plt.tight_layout()
    plt.savefig('transferred_features.png', dpi=150, bbox_inches='tight')
    plt.close()

# Progressive unfreezing strategy
def progressive_unfreezing_demo():
    """
    Demonstrate progressive unfreezing strategy
    """
    base_model = ResNet50(weights='imagenet', include_top=False, 
                         input_shape=(224, 224, 3))
    
    num_layers = len(base_model.layers)
    
    # Define unfreezing schedule
    schedule = [
        {'epoch': 0, 'unfreeze': 0, 'name': 'All Frozen'},
        {'epoch': 5, 'unfreeze': 20, 'name': 'Unfreeze Last 20'},
        {'epoch': 10, 'unfreeze': 50, 'name': 'Unfreeze Last 50'},
        {'epoch': 15, 'unfreeze': 100, 'name': 'Unfreeze Last 100'},
        {'epoch': 20, 'unfreeze': num_layers, 'name': 'Fully Unfrozen'},
    ]
    
    # Visualize schedule
    fig, ax = plt.subplots(figsize=(12, 6))
    
    for i, stage in enumerate(schedule):
        frozen = num_layers - stage['unfreeze']
        trainable = stage['unfreeze']
        
        # Stacked bar
        ax.barh(i, frozen, color='steelblue', edgecolor='black', label='Frozen' if i == 0 else '')
        ax.barh(i, trainable, left=frozen, color='orange', edgecolor='black', 
               label='Trainable' if i == 0 else '')
        
        # Add text
        ax.text(num_layers + 5, i, f"Epoch {stage['epoch']}: {stage['name']}", 
               va='center', fontsize=11, fontweight='bold')
    
    ax.set_yticks(range(len(schedule)))
    ax.set_yticklabels([f"Stage {i+1}" for i in range(len(schedule))])
    ax.set_xlabel('Number of Layers', fontsize=12, fontweight='bold')
    ax.set_title('Progressive Unfreezing Strategy', fontsize=14, fontweight='bold')
    ax.legend(loc='upper right')
    ax.grid(axis='x', alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('progressive_unfreezing.png', dpi=150, bbox_inches='tight')
    plt.close()
    
    print("Progressive Unfreezing Schedule:")
    print("="*60)
    for stage in schedule:
        print(f"Epoch {stage['epoch']:2d}: {stage['name']}")
        print(f"  Trainable layers: {stage['unfreeze']}/{num_layers}")
    print("="*60 + "\n")
