Module: Bias & Variance
1. Bias-Variance Tradeoff
📘 Theory

The bias-variance tradeoff describes how model complexity impacts prediction error:

Bias: Error due to overly simplistic assumptions. High bias models underfit data.

Variance: Error due to too much sensitivity to training data. High variance models overfit.

Total Error = Bias² + Variance + Irreducible Error

As model complexity increases:

Bias decreases

Variance increases

The goal is to find a sweet spot that minimizes total error.

📊 Visualization Idea

Use an interactive plot showing:

X-axis: Model complexity

Y-axis: Error

Three curves: Bias², Variance, Total Error

This can be animated using libraries like Plotly.js or backend-rendered via matplotlib + FastAPI API for updated data points.

🧪 Code Snippet (Python)
from sklearn.model_selection import validation_curve
from sklearn.tree import DecisionTreeRegressor
from sklearn.datasets import make_regression
import matplotlib.pyplot as plt
import numpy as np

X, y = make_regression(n_samples=500, n_features=1, noise=10)
model = DecisionTreeRegressor()
param_range = np.arange(1, 15)
train_scores, test_scores = validation_curve(
    model, X, y, param_name="max_depth", param_range=param_range,
    cv=5, scoring="neg_mean_squared_error")

train_mean = -np.mean(train_scores, axis=1)
test_mean = -np.mean(test_scores, axis=1)

plt.plot(param_range, train_mean, label="Training error")
plt.plot(param_range, test_mean, label="Validation error")
plt.xlabel("Model Complexity (max_depth)")
plt.ylabel("MSE")
plt.legend()
plt.title("Bias-Variance Tradeoff")
plt.show()

2. Underfitting vs Overfitting
📘 Theory

Underfitting: Model too simple to capture data trends (e.g., linear model on nonlinear data)

Overfitting: Model too complex, memorizes noise in training data

Good fit: Balance between bias and variance

📊 Visualization Idea

Show 3 plots with the same dataset:

Underfit: straight line

Good fit: smooth curve

Overfit: wiggly curve through all points

Animate transition between underfit → good fit → overfit using sliders or scroll-based animation.

🧪 Code Snippet
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
import numpy as np
import matplotlib.pyplot as plt

# Generate data
np.random.seed(1)
X = np.sort(5 * np.random.rand(80, 1), axis=0)
y = np.sin(X).ravel() + np.random.normal(0, 0.1, X.shape[0])

plt.figure(figsize=(12, 4))

for i, degree in enumerate([1, 4, 15]):
    poly = PolynomialFeatures(degree)
    X_poly = poly.fit_transform(X)
    model = LinearRegression().fit(X_poly, y)
    y_pred = model.predict(X_poly)
    
    plt.subplot(1, 3, i+1)
    plt.scatter(X, y, color="black", s=15)
    plt.plot(X, y_pred, label=f"Degree {degree}", color="red")
    plt.title(["Underfit", "Good Fit", "Overfit"][i])
    plt.tight_layout()

plt.show()

3. Learning Curves
📘 Theory

Learning curves show model performance as a function of training set size.

Helps diagnose under/overfitting

If train/validation scores converge at low value → underfit

If gap stays large → overfit

📊 Visualization Idea

Dual-line plot: training vs validation accuracy/MSE vs number of training samples. Animate data accumulation.

🧪 Code Snippet
from sklearn.model_selection import learning_curve
from sklearn.linear_model import Ridge
X, y = make_regression(n_samples=1000, n_features=20)
train_sizes, train_scores, val_scores = learning_curve(Ridge(), X, y, cv=5)

train_mean = np.mean(train_scores, axis=1)
val_mean = np.mean(val_scores, axis=1)

plt.plot(train_sizes, train_mean, label="Training score")
plt.plot(train_sizes, val_mean, label="Validation score")
plt.xlabel("Training Set Size")
plt.ylabel("Score")
plt.title("Learning Curve")
plt.legend()
plt.show()

4. Regularization Effects
📘 Theory

Regularization penalizes model complexity to prevent overfitting:

L1 (Lasso): Shrinks some coefficients to zero → feature selection

L2 (Ridge): Shrinks all coefficients → smooth solutions

Elastic Net: Combines both

📊 Visualization Idea

Bar plot of feature weights for Lasso, Ridge, ElasticNet

Sliders for alpha parameter

Real-time updates to weights

🧪 Code Snippet
from sklearn.linear_model import Lasso, Ridge
from sklearn.datasets import load_boston
import matplotlib.pyplot as plt

X, y = load_boston(return_X_y=True)
lasso = Lasso(alpha=0.1).fit(X, y)
ridge = Ridge(alpha=1.0).fit(X, y)

plt.bar(range(len(ridge.coef_)), ridge.coef_, alpha=0.5, label="Ridge")
plt.bar(range(len(lasso.coef_)), lasso.coef_, alpha=0.5, label="Lasso")
plt.legend()
plt.title("Regularization Effects")
plt.show()
