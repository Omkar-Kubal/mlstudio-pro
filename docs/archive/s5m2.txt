Module: Validation
1. 🧪 Holdout Validation
🎓 Theory

Holdout validation is the simplest form of model evaluation. You split your dataset into two sets:

Training set: to train the model

Testing set: to evaluate its generalization performance

Typical splits are 70/30 or 80/20. While it's fast and easy, it can give high variance estimates—performance depends heavily on the specific split.

📽️ Visual/Animation

Animate a pie chart of a dataset splitting into training and testing.

Show performance metrics changing with different train/test splits.

Use Framer Motion or D3.js for scroll-triggered animations.

🧪 Code Snippet
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = LogisticRegression()
model.fit(X_train, y_train)
predictions = model.predict(X_test)

print("Accuracy:", accuracy_score(y_test, predictions))

2. 🔁 Cross-Validation
🎓 Theory

Cross-validation improves reliability by splitting data multiple times. The most common form is k-fold cross-validation:

Split data into k subsets (folds)

Train on k-1 folds, test on the remaining one

Repeat k times and average the results

This provides a more stable estimate and reduces overfitting to a particular test set.

📽️ Visual/Animation

Animate a dataset being folded into 5 subsets.

Cycle through the active test fold.

Animate average metric accumulation.

🧪 Code Snippet
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier()
scores = cross_val_score(model, X, y, cv=5)

print("Cross-Validation Accuracy Scores:", scores)
print("Average Accuracy:", scores.mean())

3. 🎯 K-Fold vs Stratified K-Fold
🎓 Theory

K-Fold: random equal-sized splits.

Stratified K-Fold: preserves class distribution (important for classification).

Stratification ensures each fold is representative of the overall dataset — critical in imbalanced classes.

📽️ Visual/Animation

Side-by-side animation of K-Fold vs Stratified K-Fold on an imbalanced dataset.

Use color-coding to show class imbalance.

🧪 Code Snippet
from sklearn.model_selection import StratifiedKFold, KFold

kf = KFold(n_splits=5, shuffle=True, random_state=1)
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=1)

for fold, (train_idx, test_idx) in enumerate(skf.split(X, y)):
    print(f"Fold {fold+1} - Class distribution in test:", y[test_idx])

4. ⚙️ Hyperparameter Tuning
🎓 Theory

Hyperparameters are model-level settings (like tree depth, learning rate).
Tuning finds the best combo for optimal performance:

Too small = underfitting

Too large = overfitting

📽️ Visual/Animation

Show a model accuracy curve vs different hyperparameter values (e.g., depth = 1 to 10).

Show overfitting by visualizing decision boundaries for different parameter values.

🧪 Code Snippet
from sklearn.model_selection import cross_val_score

for depth in range(1, 11):
    model = RandomForestClassifier(max_depth=depth, random_state=0)
    scores = cross_val_score(model, X, y, cv=5)
    print(f"Depth {depth}: Accuracy = {scores.mean():.2f}")

5. 🔍 Grid Search vs Random Search
🎓 Theory

Grid Search: Exhaustive search over specified parameter combinations.

Random Search: Randomly sample parameter combinations — more efficient in high dimensions.

Trade-off:
Grid = full coverage, slow
Random = faster, approximate

📽️ Visual/Animation

Grid vs Random point plots over a parameter space (learning rate vs depth).

Heatmap showing performance over combinations.

🧪 Code Snippet
from sklearn.model_selection import GridSearchCV, RandomizedSearchCV

param_grid = {'n_estimators': [10, 50, 100], 'max_depth': [2, 4, 6]}
grid = GridSearchCV(RandomForestClassifier(), param_grid, cv=3)
grid.fit(X, y)
print("Best Grid Params:", grid.best_params_)

from scipy.stats import randint
param_dist = {'n_estimators': randint(10, 200), 'max_depth': randint(1, 10)}
random_search = RandomizedSearchCV(RandomForestClassifier(), param_distributions=param_dist, n_iter=10, cv=3, random_state=0)
random_search.fit(X, y)
print("Best Random Params:", random_search.best_params_)
