Module: Classification (Complete, In-Depth)
1. What Is Classification (Foundational Theory)
What classification really is

Classification is the task of assigning inputs to discrete categories.

But fundamentally, classification is about regions in space, not labels.

Each classifier learns:

“Which region of input space belongs to which class?”

Key difference from regression

Regression predicts values

Classification predicts membership

Internally:

Models compute a score

Scores are converted into class decisions

Mental model the learner must keep

A classifier does not say what something is
It says which side of a boundary it falls on

Visualization

2D feature space

Points colored by class

No model yet — just raw distribution

Practice (Dataset)

2. Decision Boundaries (Core Geometry)
Theory

A decision boundary separates regions of different class predictions.

Key insight:

Every classifier = a boundary + a rule

Boundary types:

Linear (line / hyperplane)

Non-linear (curves, regions)

Piecewise (trees)

Visualization

Scatter plot

Boundary drawn as contour

Background shaded by predicted class

Animation

Boundary morphs as parameters change

Smooth transitions (Framer Motion)

Learner toggles:

Linear vs non-linear

Watches boundary reshape

6. KNN Classification
Theory

KNN classifies by local majority vote.

No training:

Stores data

Measures distance

Prediction = most common class among neighbors

k nearest neighbors glow
