# V2 Visual Governance

**Version:** 2.0.0  
**Status:** FINAL  
**Authority:** This document governs all visual primitive usage in V2.

---

## Visual Primitive Status

Visual primitives are **implemented but dormant**.

The following primitives exist in `runtime/visual_runtime/`:
- Projection (PCA, t-SNE, UMAP)
- Sequence (RNN/LSTM flow)
- Attention (Transformer heatmaps)
- Filters (CNN filters/feature maps)

**These primitives are not activated in V2.**

---

## Visual Properties

Visuals are:
- **Optional** — The system functions fully without them
- **Non-authoritative** — They do not define truth
- **Non-evaluative** — They do not affect scoring

---

## Visual Constraints

Visuals must:
- Never carry meaning alone
- Never affect grading
- Never introduce UI language
- Never be required for comprehension

---

## Subject Independence

No subject requires visuals to be understood.

All 84 labs are comprehensible through:
- Theory text
- Code execution
- Output contracts

Visuals, if ever activated, would provide supplementary illustration only.

---

## Enforcement

Any change that violates this governance requires a new version.

V2 visuals remain dormant.
