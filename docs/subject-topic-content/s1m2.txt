1. Theory

Machine Learning models do not learn fixed values — they learn uncertainty.

Probability theory provides the language to describe uncertainty, and it starts with random variables and probability distributions.

2. Random Variables

A random variable is a numerical outcome of a random process.

It is not random itself — it maps randomness to numbers.

Types of Random Variables
Discrete Random Variables

Take countable values

Examples:

Dice rolls

Number of clicks

Class labels

Continuous Random Variables

Take uncountably infinite values

Examples:

Height

Time

Loss values

Key distinction

Discrete → probabilities

Continuous → probability densities

Conditional Probability & Bayes’ Theorem

1. Why This Topic Exists

Up to now, probability answered:

“How likely is an event?”

But real systems ask a more powerful question:

“How likely is an event given that something else already happened?”

This is the backbone of:

Learning from evidence

Updating beliefs

Classification probabilities

Bayesian Machine Learning

Without conditional probability, learning from data is impossible.

Intuition (very important)

Conditional probability shrinks the universe.

Instead of asking:

“How often does A happen?”

You ask:

“How often does A happen inside the world where B is already true?”

Example

A = “User clicks”

B = “User saw the ad”

You must condition on B, otherwise the probability is meaningless.

This directly maps to:

Feature conditioning

Context-aware prediction

Evidence-based inference

Mental Model

Universe = all outcomes

B = a subset of the universe

A ∩ B = overlap

Conditional probability zooms into B only.

This intuition prevents 90% of beginner mistakes.

8. Code (Python – Practical)
Simple Bayesian Update
# Prior belief
P_disease = 0.01

# Test accuracy
P_positive_given_disease = 0.95
P_positive_given_no_disease = 0.05

# Evidence
P_positive = (
    P_positive_given_disease * P_disease +
    P_positive_given_no_disease * (1 - P_disease)
)

# Posterior
P_disease_given_positive = (
    P_positive_given_disease * P_disease
) / P_positive

print(P_disease_given_positive)


Key lesson
Even accurate tests can produce low-confidence predictions if priors are low.

Topic

Law of Large Numbers (LLN)

1. Why This Topic Exists

One of the most common beginner confusions is:

“If probability says something is likely, why don’t I always see it happen?”

The Law of Large Numbers explains when probability becomes reliable and why small datasets mislead models.

This topic is fundamental to:

Training ML models

Trusting evaluation metrics

Understanding convergence

Avoiding false confidence

2. The Core Idea (Plain Language)

The Law of Large Numbers states:

As the number of observations increases, the average of the results converges to the expected value.

It does not say:

Outcomes become predictable

Randomness disappears

It says:

Aggregates stabilize

Estimates improve with data

4. Weak vs Strong Law (Conceptual Only)

You do not need proofs, but you should understand meaning:

Version	Meaning
Weak LLN	Converges in probability
Strong LLN	Converges almost surely

For ML:

Weak LLN intuition is sufficient

Both explain why training improves with data

5. Why Small Samples Lie

With small samples:

Variance dominates

Random streaks appear meaningful

Models overfit noise

This is why:

Early metrics fluctuate wildly

Validation scores jump

Overconfidence is dangerous
