Figure: Components of descriptive statistics (distribution, central tendency, variability). Descriptive statistics summarize and organize the main features of a dataset
. They focus on the distribution of data (frequency of values), the central tendency (typical values like mean, median, mode), and the variability or spread (range, variance, standard deviation)
. Common measures include:
Mean (average): sum of values divided by count
.
Median: middle value when data are sorted
.
Mode: most frequent value
.
Range: max minus min.
Variance/Std Dev: average squared deviation from mean / its square root
.
These metrics give a concise “summary” of data without inferring beyond it
.

Population vs Sample

1. Theory

In statistics, data always comes from somewhere. Understanding where it comes from determines how reliable your conclusions are.

Population

A population is the complete set of all possible observations you care about.

Examples:

All users of an app

Every house in a city

Every transaction in a year

Key idea:

A population represents the entire reality you want to understand.

However, populations are often:

Too large

Too expensive

Sometimes impossible to measure fully

Sample

A sample is a subset of the population used to estimate population properties.

Key idea:

A sample is a proxy for reality, not reality itself.

We calculate statistics on samples (sample mean, sample variance) to infer population parameters (true mean, true variance).

Why This Distinction Matters

Machine Learning models never see the population.
They learn patterns from samples.

If your sample is:

Biased → your model is biased

Too small → your model overfits

Not representative → your predictions fail in production

This is the foundation of:

Generalization

Overfitting

Train / test splits

Model evaluation

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# True population
population = np.random.normal(loc=50, scale=10, size=100000)
population_mean = population.mean()

sample_sizes = [10, 30, 100, 500]
sample_means = []

for size in sample_sizes:
    sample = np.random.choice(population, size=size)
    sample_means.append(sample.mean())

print("Population mean:", population_mean)
print("Sample means:", sample_means)

Visualizing the Effect of Sample Size
plt.figure(figsize=(8, 4))
plt.hist(population, bins=100, alpha=0.4, label="Population")

for size in sample_sizes:
    sample = np.random.choice(population, size=size)
    plt.axvline(sample.mean(), linestyle="--", label=f"Sample mean (n={size})")

plt.axvline(population_mean, color="black", linewidth=2, label="Population mean")
plt.legend()
plt.title("Population vs Sample Means")
plt.show()

Measures of Central Tendency

1. Theory

When we summarize data, the first question we ask is:

“Where is the center?”

Measures of central tendency answer this by identifying a typical or representative value of a dataset. However, there is no single “best” center—each measure captures a different notion of typicality.

The three primary measures are:

Mean

Median

Mode

Understanding when and why to use each is critical for data analysis and machine learning.

Mean (Arithmetic Average)

The mean is the sum of all values divided by the number of values.

Intuition

The mean is the balance point of the data.

Every value contributes equally.

Sensitive to extreme values (outliers).

When mean works well

Symmetric distributions

No extreme outliers

Many ML algorithms implicitly optimize around the mean (e.g., MSE in regression)

Failure case
A single extreme value can pull the mean far from where most data lies.

Median (Middle Value)

The median is the middle value when data is sorted.

Intuition

The median splits the data into two equal halves.

It depends only on order, not magnitude.

Robust to outliers.

When median works well

Skewed distributions

Income, house prices, salaries

When fairness or robustness matters

Key idea

The median answers: “What does a typical data point look like?”

Mode (Most Frequent Value)

The mode is the value that appears most often.

Intuition

Captures commonness, not centrality.

Useful for categorical or discrete data.

Important properties

A dataset can have:

One mode (unimodal)

Multiple modes (multimodal)

No mode

When mode matters

Categorical features

Discrete outcomes

Frequency-based decisions

Why These Are Different

Consider salaries:

Mean → influenced by billionaires

Median → typical worker

Mode → most common salary band

Machine learning relevance

Regression minimizes error around the mean

Robust models often implicitly align closer to the median

Classification frequency aligns with mode

Outliers & Anomalies

1. Theory

Not all data points are equal.

Some observations do not follow the general pattern of the data. These are called outliers or anomalies.
They can either be:

Errors (measurement, logging, data entry)

Rare but valid events (fraud, failures, spikes)

Signals that matter more than averages

Understanding outliers is critical because a single extreme value can dominate model behavior.

Outliers vs Anomalies
Term	Meaning
Outlier	A data point far from the rest, defined statistically
Anomaly	A data point that is unusual in context

Example:

Salary of ₹10 crore → statistical outlier

Sudden spike in network traffic → anomaly (possibly an attack)

Why Outliers Exist

Outliers appear due to:

Measurement errors

Data corruption

Rare real-world events

Distribution tail behavior (high kurtosis)

Key insight

Outliers are not always bad — removing them blindly destroys information.

Why Outliers Matter in ML

Mean-based models are extremely sensitive

Distance-based models amplify them

Scaling can exaggerate their effect

They influence:

Regression coefficients

Decision boundaries

Loss values

Example:

MSE explodes with outliers

MAE is more robust

const width = 600, height = 300;
const svg = d3.select("#outliers")
  .append("svg")
  .attr("width", width)
  .attr("height", height);

let data = d3.range(40).map(() => d3.randomNormal(50, 5)());

function draw() {
  svg.selectAll("*").remove();

  const mean = d3.mean(data);

  svg.selectAll("circle")
    .data(data)
    .enter()
    .append("circle")
    .attr("cx", d => d * 4)
    .attr("cy", height / 2)
    .attr("r", 3)
    .attr("fill", "#aaa");

  svg.append("line")
    .attr("x1", mean * 4)
    .attr("x2", mean * 4)
    .attr("y1", 0)
    .attr("y2", height)
    .attr("stroke", "#ff6b6b")
    .attr("stroke-width", 2);
}

draw();

d3.select("#add").on("click", () => {
  data.push(120);
  draw();
});
</script>

4. Code (Python – Practical)
IQR-Based Detection
import numpy as np
import pandas as pd

data = pd.Series([10, 12, 13, 14, 15, 100])

Q1 = data.quantile(0.25)
Q3 = data.quantile(0.75)
IQR = Q3 - Q1

outliers = data[(data < Q1 - 1.5 * IQR) | (data > Q3 + 1.5 * IQR)]
print(outliers)

Isolation Forest (ML-Based)
from sklearn.ensemble import IsolationForest
import numpy as np

X = np.array([[x] for x in data])

model = IsolationForest(contamination=0.1)
preds = model.fit_predict(X)

print(preds)  # -1 = anomaly, 1 = normal
